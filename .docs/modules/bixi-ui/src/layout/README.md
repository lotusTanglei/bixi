# layout 布局组件

应用布局组件目录，提供经典、横向、分栏、默认四种布局模式。

## 目录结构

| 目录/文件 | 说明 |
|-----------|------|
| `index.vue` | 布局入口组件，根据配置切换布局模式 |
| `navBars/` | 顶部导航栏组件 |
| `navMenu/` | 侧边导航菜单组件 |
| `main/` | 主内容区域组件 |
| `logo/` | Logo 组件 |
| `footer/` | 页脚组件 |
| `component/` | 布局辅助组件 |
| `lockScreen/` | 锁屏组件 |
| `routerView/` | 路由视图容器 |

## 布局模式

1. **经典布局** — 左侧菜单 + 顶部导航
2. **横向布局** — 顶部菜单导航
3. **分栏布局** — 左侧分栏 + 子菜单
4. **默认布局** — 标准后台管理布局
