# src 前端源码根目录

Bixi 前端项目源码根目录，基于 Vue 3 + TypeScript + Element Plus 构建。

## 目录结构

| 目录 | 说明 |
|------|------|
| `api/` | 后端 API 接口定义 |
| `assets/` | 静态资源（图片、图标、样式） |
| `components/` | 公共组件（27+ 个） |
| `directive/` | Vue 自定义指令 |
| `hooks/` | 组合式函数（Composables） |
| `i18n/` | 国际化配置 |
| `layout/` | 布局组件 |
| `router/` | 路由配置 |
| `stores/` | Pinia 状态管理 |
| `theme/` | 主题样式 |
| `types/` | TypeScript 类型定义 |
| `utils/` | 工具函数集 |
| `views/` | 页面视图组件 |

## 入口文件

| 文件 | 说明 |
|------|------|
| `main.ts` | TypeScript 应用入口 |
| `main.js` | JavaScript 应用入口（兼容） |
| `App.vue` | 根组件 |
