# router 路由配置

Vue Router 路由配置目录，支持前端静态路由和后端动态路由两种模式。

## 目录结构

| 文件 | 说明 |
|------|------|
| `index.ts` | 路由实例创建与全局守卫 |
| `route.ts` | 路由工具函数 |
| `frontEnd.ts` | 前端静态路由模式，路由表写在前端代码中 |
| `backEnd.ts` | 后端动态路由模式，从服务端获取菜单并动态生成路由 |
| `modules/` | 路由模块目录，按功能模块拆分路由配置 |

## 路由模式

- **前端模式**（`frontEnd.ts`）：路由表硬编码在前端，适合简单项目
- **后端模式**（`backEnd.ts`）：根据用户权限从后端动态加载路由，推荐生产使用

## 路由守卫

在 `index.ts` 中配置全局前置守卫，处理：
- 登录状态校验
- 动态路由加载
- 页面标题设置
- NProgress 进度条
