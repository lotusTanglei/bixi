# public 静态资源

前端项目公共静态资源目录，存放不经过构建工具处理的静态文件。

## 目录说明

本目录下的文件会被直接复制到构建输出目录，不经过 Vite 编译处理。

## 目录结构

| 文件/目录 | 说明 |
|-----------|------|
| `index.html` | 应用入口 HTML 模板 |
| `favicon.ico` | 网站图标 |
| `assets/` | 静态资源（字体文件等） |

## 注意事项

- 此目录下的文件通过绝对路径引用（如 `/favicon.ico`）
- 不会被 Vite 进行哈希处理或压缩
- 适合存放不需要模块化引入的资源
