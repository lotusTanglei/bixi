# Main 整合记录（2026-09-21）

本次从已含五个 Bixi Skills 的 `adf5a6e` 整合当前已实现的工作流、安全、前端、SQL 与运行脚本。已有本地及 GitHub 分支的提交均包含在该基线中；额外开发文件在独立工作树中整合并验证，原开发工作区及用户维护的 `.chiwen.state.json` 保持不变。

## 收录范围

- cloud/single 共用的工作流引擎开关、请假审批、请求幂等、前端失败恢复和接口契约。
- 已实现的 Outbox、Inbox 与本地可靠投递原语及数据库迁移；未将原语描述为已接通工作流的完整异步链路。
- 认证、管理权限、通知归属和发布重试、权限缓存一致性、令牌状态检查、审计脱敏与代理路径修复。
- 五个 Skills、需求/设计/计划及当前开发进度文档。

整合时补齐了既有库的 18 项安全权限迁移；修复真实 Excel `BindingResult` 导致审计丢失、普通用户个人资料被管理权限阻断、公共退出入口审计缺少用户 ID，以及重复运行验收时日志分页未排序的问题。数据库测试仅清理本次成功创建的容器 ID；去除了重复的 Inbox 初始化建表段，补齐前端 Docker 构建辅助脚本和 README 的双模说明。

真实启停验收还发现工作流关闭时缓存的用户权限会在再次开启后导致 403。UPMS 在 cloud/single 启动就绪前失效 `user_details` 区域，使用户名和手机号登录重新加载当前权限；Token、会话和流程数据不受影响。已补多次重启的回归，先复现失败后验证修复。最终比对也收录了已完成的事件 codec 精确整数修复：接受规范化后的整数指数形式，继续拒绝小数及溢出。
