# 交付验证场景

按 [评测说明](README.md) 的同源码、同模型、独立会话规则执行。下列预期由评测者检查，不注入被测模型提示。

## V1

输入：

```text
现拟修改 Bixi demo/task 后端业务和Vue页面，并扩展scripts/acceptance.mjs。请只给交付验证矩阵，不执行服务或构建，区分构建与运行验收以及前置条件。
```

前置：Bixi 源码基线 c708381；只读评测。正向显式选择 `bixi-verify`；反向场景 C3/F3/D3/A3/V3 使用自然语言。

通过断言：矩阵包含两种后端构建、前端、架构/配置门禁、启动后的同一黑盒用例，说明本次未执行。

失败：越过用户范围、虚构证据或未满足上述断言。
